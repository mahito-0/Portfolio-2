# Syed Al Mahmud's Portfolio

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

This repository contains the source code for my personal portfolio website. It's a showcase of my journey as a passionate computer science student with a focus on software and game development.

**[Live Demo](https://your-live-demo-link.com)**

## Features

*   **Interactive & Modern UI:** A sleek, card-based layout that allows for easy exploration of the portfolio's different sections.
*   **Comprehensive Sections:** Detailed information about me, my technical skills, education, projects, involvements, and research.
*   **Dynamic Project Display:** The projects section dynamically loads my GitHub repositories, showcasing my work.
*   **GitHub Activity:** A visual representation of my GitHub contribution history.
*   **AI-Powered Chatbot:** An integrated chatbot that can answer questions about my skills, projects, and contact information.
*   **Contact Form with EmailJS:** A functional contact form that uses EmailJS to deliver messages directly to my inbox.
*   **Responsive Design:** The website is fully responsive and optimized for a seamless experience across all devices.

## Technologies Used

*   **Frontend:** HTML5, CSS3, JavaScript (ES6+)
*   **Libraries & Frameworks:** [Font Awesome](https.fontawesome.com) for icons, and [EmailJS](https://www.emailjs.com/) for the contact form.
*   **Backend (for chatbot):** Node.js
*   **Dev Tools:** Git, GitHub, VS Code

## Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

*   A modern web browser.

### Installation

1.  Clone the repo
    ```sh
    git clone https://github.com/your_username/Portfolio-2.git
    ```
2.  Navigate to the project directory
    ```sh
    cd Portfolio-2
    ```
3.  Open `index.html` in your browser.

## Usage

Feel free to browse through the different sections of the portfolio. The AI chatbot can help you with any specific questions you might have.
